# 紅鯡魚

## 定義
- 紅鯡魚是讓人偏離正確方向的東西，可能是故意也可能是無意 [S3]
- 在小說中，它是讓讀者走向錯誤結論的假線索，用來製造懸疑或讓反轉更震撼，作者通常會在最後解開它 [S3]

## 名稱由來
- 1807 年記者 William Cobbett 寫到用煙燻鯡魚的氣味把獵犬引離野兔，這個故事讓比喻用法普及 [S3]
- 這不是真實存在的狩獵做法，只是 Cobbett 的比喻故事 [S3]

## 例子
- 福爾摩斯的血字的研究中，現場出現德文 Rache，意思是復仇，讓警方和讀者以為凶手是德國人 [S3]

## 和邏輯謬誤的區別
- 在辯論中，紅鯡魚謬誤是提出無關的論點來轉移焦點 [S3]

## 整理
紅鯡魚和 [[unreliable-narrator]] 都在誤導讀者，差別在紅鯡魚是故事裡的一條假線索，不可靠敘事者是說故事的方式本身不可信。如何讓假線索不違反公平，見 [[clue-design]]。
