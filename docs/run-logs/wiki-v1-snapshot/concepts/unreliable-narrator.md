# 不可靠敘事者

## 定義
- 說故事的人本身不可信，可能說謊、隱瞞或理解錯誤，通常是第一人稱 [S4]
- Wayne Booth 在 1961 年的 The Rhetoric of Fiction 提出這個詞 [S4]

## 兩種類型
- 無意的不可靠：敘事者年紀小或經驗不足，看不懂發生的事 [S4]
- 有意的不可靠：敘事者有隱藏的動機，刻意扭曲事件 [S4]

## 讀者怎麼發現
- 有時一開始就很明顯，有時要等後面的資訊和敘事者說法矛盾才察覺 [S4]

## 在推理小說中
- 推理作家用它誤導讀者，再在真相揭曉時推翻讀者的假設 [S4]
- 1926 年的羅傑艾克洛命案是經典例子，電影則有記憶拼圖、刺激驚爆點等 [S4]

## 整理
Knox 第一條要求凶手不能是讀者看過內心想法的角色，不可靠敘事者正好挑戰這種限制，見 [[knox-decalogue]]。和 [[red-herring]] 的差別在於誤導發生的層次不同。
