# 給讀者的挑戰書

- Ellery Queen 系列從 1929 到 1971 年，會在讀者和偵探都拿到全部線索時插入挑戰書，看誰先解開 [S7]
- 現代作家也有類似做法，例如把解答頁封起來，或讓敘事者直接告訴讀者線索在哪 [S7]
- Carr 的密室講義也是偵探直接對讀者說話 [S5]

## 整理
挑戰書等於作者公開宣告：線索已經給完了。這是 [[fair-play]] 最直接的承諾，也呼應 [[locked-room]] 中 Fell 博士打破第四面牆的設計。
