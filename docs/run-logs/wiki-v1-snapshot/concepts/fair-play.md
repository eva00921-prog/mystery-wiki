# 公平推理

## 定義
- 公平推理是作者把所有線索都給讀者，讓讀者和偵探比賽，線索藏在眼前 [S7]
- 黃金時代的作者與讀者把推理小說當成遊戲 [S1]，Van Dine 也說作者必須對讀者公平 [S2]

## 兩套經典規則的共同點
- 偵探不能是凶手，Knox 與 Van Dine 都這樣規定 [S1][S2]
- 不能靠超自然或運氣破案 [S1][S2]
- 偵探發現的線索要讓讀者知道 [S1][S2]

## 現代做法
- 近年因為經典作品重新出版、各國作品翻譯與 podcast，公平推理重新流行 [S7]
- 例如在書末附上線索索引，標出每條線索出現在哪一頁 [S7]
- Ellery Queen 會在結局前插入給讀者的挑戰書，見 [[challenge-to-reader]] [S7]

## 整理
公平不代表簡單。作者可以誤導讀者，見 [[red-herring]]，但真線索一定要在場，見 [[clue-design]]。規則來源見 [[knox-decalogue]] 與 [[van-dine-rules]]。
