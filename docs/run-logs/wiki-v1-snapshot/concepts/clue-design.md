# 線索設計

## 真線索
- 讀者要和偵探拿到相同的線索，而且線索要清楚呈現 [S2]
- 線索要能完整指向凶手 [S2]
- 凶手要在前段出場 [S1]

## 假線索
- 作者會用假線索誤導讀者，高手會讓最不可能的嫌疑人成為凶手 [S1]
- 假線索也就是紅鯡魚，最後要被解開 [S3]

## 事後驗證
- 有作家在書末附上線索索引，讓讀者回頭確認線索真的出現過 [S7]

## 整理
誤導和公平並不衝突：Van Dine 允許凶手對偵探使用詭計，只要真線索同時存在、假線索在結局有合理解釋，遊戲就仍然公平。
一個好的線索組合是：幾條指向真凶的關鍵證據，加上幾條指向別人的 [[red-herring]]。相關規則見 [[fair-play]]。
