# Knox 十誡

Ronald Knox 在 1929 年把推理遊戲的規則整理成十條，偵探俱樂部成員承諾遵守 [S1]。

1. 凶手要在故事前段出場，但不能是讀者看過內心想法的角色 [S1]
2. 排除超自然的解釋 [S1]
3. 密室或密道最多只能有一個 [S1]
4. 禁止未知的毒藥，或需要長篇科學解釋的裝置 [S1]
5. 禁止中國人角色，這反映 1920 年代西方小說對華人的刻板印象，是歷史背景而不是寫作建議 [S1]
6. 偵探不能靠巧合或直覺破案 [S1]
7. 偵探不能是凶手 [S1]
8. 偵探發現的線索都要讓讀者知道 [S1]
9. 偵探的助手也就是華生，要對讀者坦白想法，而且略笨於一般讀者 [S1]
10. 雙胞胎或替身要事先鋪陳 [S1]

## 整理
十條規則大致可以分成三類：讀者要拿得到線索，例如第 1、8、9 條；答案要合理，例如第 2、3、4、10 條；推理過程要靠邏輯，例如第 6、7 條。
這些規則也會被刻意打破，見 [[unreliable-narrator]]。和 Van Dine 的比較見 [[van-dine-rules]]。
