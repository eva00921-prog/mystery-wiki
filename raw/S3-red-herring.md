# S3　Red herring

原始資料卡。內容是閱讀來源後的改寫摘要，不是原文複製；每條事實有編號，Wiki 頁面引用時寫成 [S3]。
這個資料夾是唯讀的，ingest 之後不再修改。

- S3-F1　紅鯡魚是誤導或分散注意力的東西，會讓人偏離重要問題、論點或破案方向，可能是故意也可能是無意。
- S3-F2　1807 年記者 William Cobbett 寫到小時候用煙燻鯡魚的氣味把獵犬引離野兔，這個故事普及了比喻用法，但並不是真實的狩獵做法。
- S3-F3　在小說中，紅鯡魚可以是讓讀者走向錯誤結論的假線索，用來製造懸疑或讓反轉更震撼，作者通常會在最後解開它。
- S3-F4　例子：福爾摩斯的血字的研究中，凶手寫下德文 Rache，意思是復仇，讓警方和讀者誤以為凶手是德國人。
- S3-F5　例子：達文西密碼的 Aringarosa 主教看似陰謀核心，最後發現他也被真正的反派利用，他的名字在義大利文裡大致就是紅鯡魚的意思。
- S3-F6　在邏輯上，紅鯡魚謬誤是提出看似相關但其實無關的論點來轉移焦點，和稻草人謬誤不同，它不是扭曲對方，而是換話題。
